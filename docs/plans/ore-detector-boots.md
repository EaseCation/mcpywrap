# 矿物探测鞋与最小 QuMod 支持

## 已接受的计划（2026-09-27）

实践项目位于 `D:/coding/ModsDev/ore-detector-boots`，独立 Git 管理（按用户后续指示替代 examples 目录）。工具修复在 mcpywrap 仓库维护。游戏、缓存、构建产物不提交。

目标：十种可合成、可穿戴的探测鞋，服务端扫描当前维度已加载矿石，客户端以飞行粒子表示方向，以短音节奏表示距离。基线网易 3.9.0.401155、QuMod 提交 a07430aaaa6dce5f1ef68de3fda52ea4b9366c2c，保留许可。每个原版 API/事件/组件必须经 netease-modsdk MCP 查证；文档与实机证据分开。

基础鞋配方：铜/指南针/铜，红石/铁靴/红石，铜/红石/铜。校准芯中心为指南针；煤4颗十字，铜8锭，石英8颗，铁2块6锭，红石4块4粉，青金石4块4颗，金4块4锭，钻石2块6颗，绿宝石4块4颗，下界合金8锭。混合配方材料块依左上、右上、左下、右下排列。基础鞋加校准芯合成成品。鞋护甲2、半径8，不为探测额外扣耐久。

服务端：换装事件和低频校验；全局每tick最多256次方块读取、玩家公平轮转、近到远分批扫描，候选每0.5秒复核、目标切换迟滞；脱鞋/死亡/退出/维度变化清理。未知区块不当作空气，不强制加载。不区分人工与自然矿石。客户端：QuMod定向RPC、维度和递增序号、2秒过期；粒子从脚边向目标飞行1～2格；提示音从0.2～1.2秒连续变化，采用单次短音，不依赖播放后立即停止。

美术复用原版鞋模型；开发侧脚本生成矿物色图标/盔甲贴图和校准装置纹样，不调用生图API。资源与游戏代码单独打包。

新增 `[[tool.mcpywrap.code_libraries]]`：name/git/rev/subdir/target。sync显式获取固定来源与记录摘要；build/package/run/dev不联网隐式更新。完整目录安装到所属Mod，不全局共享QuMod实例；拒绝路径越界、目标重叠与手写文件冲突。更新/失败保护已有缓存和产物。运行保持原项目的配置与会话身份，并消费共同组装结果。不建设中央仓库、范围求解器、通用加载器、MCDevTool配置兼容。
